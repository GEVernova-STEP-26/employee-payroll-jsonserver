

# Employee Payroll App

This is a simple and responsive Employee Payroll application built using **HTML, CSS, and Vanilla JavaScript**, with **JSON Server** acting as a mock backend.

It allows you to manage employee records with full CRUD functionality.

---

## What You Can Do

* Add new employees
* View employee list
* Edit employee details
* Delete employees
* Search and sort employees
* See basic dashboard stats (total employees, salary info)



## How to Run

1. Go to the project folder:

   ```bash
   cd EmployeePayrollJson
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start JSON Server:

   ```bash
   npm start
   ```

4. Open `index.html` in your browser
   (Using VS Code Live Server is recommended)

---
